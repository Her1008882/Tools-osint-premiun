Responsible Use

ToolsRatV1 adalah dashboard demonstrasi untuk riset keamanan defensif, inventaris aset, validasi data, dan dokumentasi. Fitur yang mengidentifikasi, melacak, mengekspos data pribadi, mencari lokasi seseorang, membobol akun, atau melakukan doxing tidak disediakan.

Database disimpan di browser perangkat ini menggunakan IndexedDB. Data tidak otomatis tersinkron ke server dan dapat hilang jika data situs/browser dihapus. Jangan simpan password, token rahasia, atau data sensitif.

Database & Privacy

Semua catatan dan inventaris tersimpan secara lokal. Tools browser berjalan di perangkat Anda. Modul yang memerlukan layanan eksternal/API ditandai sebagai panduan atau placeholder dan tidak mengklaim hasil scan palsu.

Website Hacking Academy

Materi edukasi membahas OWASP Top 10, SQL injection prevention, XSS, CSRF, security headers, session security, file upload, CORS, dan responsible disclosure. Praktik hanya pada lab atau aset yang Anda miliki / diizinkan.

Deployment

Untuk multi-user, login, sinkronisasi, role admin, dan database server, hubungkan frontend ini ke backend Node.js + PostgreSQL/MySQL dengan autentikasi dan audit log.
